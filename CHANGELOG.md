## [0.1.0] - 2026-08-01

### Added

- Initialized the AI Media Factory monorepo.
- Scaffolded the enterprise AI-OS directory structure, including apps, packages, agents, docs, knowledge, configs, infra, data, assets, experiments, and workflows.
- Established the foundation for an event-driven architecture spanning the task queue and event bus.
- Added the runtime artifact storage plane with cache, exports, renders, queue, and templates subfolders.
- Added project-standard governance documents, including the code of conduct, security policy, and this changelog.

### Changed

- Adopted Keep a Changelog and Semantic Versioning as the project standards for release documentation.
