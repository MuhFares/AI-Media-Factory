# Reports Archive

Archive of generated executive and analytics reports for AI Media Factory.

Contents are runtime-generated and git-ignored; this README and .gitkeep anchor the folder in version control.

## What lives here

- Executive reports: for example, CEO weekly executive reports summarizing performance, decisions, and outlook.
- Analytics reports: periodic analytical summaries derived from persisted metrics and learned patterns.

Reports are retained here as an auditable historical record of what was reported and when.
