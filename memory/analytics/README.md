# Analytics Memory

Persisted analytical memory for AI Media Factory.

Contents are runtime-generated and git-ignored; this README and .gitkeep anchor the folder in version control.

## What lives here

- Rolling metrics: time-windowed aggregates retained for trend analysis and comparison.
- Learned performance patterns: durable signals the platform has derived about what performs well, for whom, and under what conditions.

This memory allows analytical insight to accumulate over time rather than being recomputed from scratch on each run.
