# Assets

Brand and media assets for the AI Media Factory platform. This area holds the reusable creative material that content production draws upon, from typography and logos to audio, video, imagery, and templates.

## Binaries are git-ignored placeholders

Media binaries are git-ignored. The folders in this area are anchored by their README and hold placeholder entries. Actual binary assets are stored in the platform's asset store and object storage, not committed to version control.

## Subfolders

| Subfolder | Purpose |
| --- | --- |
| `fonts/` | Typography assets and font families. |
| `logos/` | Brand logos and mark variations. |
| `music/` | Background music and audio beds. |
| `voices/` | Voice models and samples for text-to-speech and narration. |
| `videos/` | Source and reusable video assets. |
| `images/` | Source and reusable image assets. |
| `thumbnails/` | Thumbnail imagery for published content. |
| `templates/` | Reusable design and video templates. |
