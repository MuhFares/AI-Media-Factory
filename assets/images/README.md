# Assets / Images

Source and reusable image assets used in media production.

## What belongs here

- Stock and source images cleared for platform use.
- Reusable graphics, backgrounds, and overlays.
- License records for each image.

## Binaries are git-ignored placeholders

Image binary files are git-ignored placeholders. Actual image files are stored in the platform's asset store and object storage, not committed to version control. This folder is anchored by its README.

## Naming conventions

- Organize by category and intended use.
- Include dimensions and format in the file name where useful.
