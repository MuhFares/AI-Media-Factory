# Assets / Fonts

Typography assets and font families used across produced content and brand surfaces.

## What belongs here

- Font families licensed for platform use.
- Weight and style variants belonging to each family.
- License records for each font.

## Binaries are git-ignored placeholders

Font binary files are git-ignored placeholders. Actual font files are stored in the platform's asset store, not committed to version control. This folder is anchored by its README.

## Naming conventions

- Organize by family, then by weight and style.
- Use the canonical family name in kebab-case for folder names.
