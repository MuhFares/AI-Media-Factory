# Assets / Templates

Reusable design and video templates. This folder holds the parameterized layouts and compositions that production uses to generate consistent content at scale.

## What belongs here

- Design templates for images and graphics.
- Video templates defining structure, timing, and placeholders.
- Template documentation describing parameters and intended use.

## Binaries are git-ignored placeholders

Template binary and project files are git-ignored placeholders. Actual template files are stored in the platform's asset store, not committed to version control. This folder is anchored by its README.

## Naming conventions

- Name templates by content type and format, in kebab-case.
- Version templates so downstream pipelines can pin to a known revision.
