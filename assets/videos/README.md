# Assets / Videos

Source and reusable video assets used in media production.

## What belongs here

- Stock and source video clips cleared for platform use.
- Reusable video segments such as intros, outros, and transitions.
- License records for each clip.

## Binaries are git-ignored placeholders

Video binary files are git-ignored placeholders. Actual video files are stored in the platform's asset store and object storage, not committed to version control. This folder is anchored by its README.

## Naming conventions

- Organize by category and intended use.
- Include resolution and duration in the clip name where useful.
