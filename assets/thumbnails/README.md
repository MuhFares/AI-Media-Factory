# Assets / Thumbnails

Thumbnail imagery for published content. This folder holds the preview images that represent content across publishing platforms.

## What belongs here

- Thumbnail images produced for published pieces.
- Thumbnail variants sized for different platforms.

## Binaries are git-ignored placeholders

Thumbnail binary files are git-ignored placeholders. Actual thumbnail files are stored in the platform's asset store and object storage, not committed to version control. This folder is anchored by its README.

## Naming conventions

- Name thumbnails by content identifier and target platform.
- Include dimensions in the file name to distinguish platform sizes.
