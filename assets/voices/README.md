# Assets / Voices

Voice models and samples for text-to-speech and narration. This folder holds the voice profiles and reference audio the platform uses to generate spoken content.

## What belongs here

- Voice profile definitions used for TTS and narration.
- Reference voice samples.
- License and consent records for each voice.

## Binaries are git-ignored placeholders

Voice model and sample binaries are git-ignored placeholders. Actual voice files are stored in the platform's asset store, not committed to version control. This folder is anchored by its README.

## Naming conventions

- Name voices by profile identity, language, and style, in kebab-case.
- Keep language and locale explicit for each voice.
