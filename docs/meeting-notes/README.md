# Meeting Notes

This directory is the archive of meeting notes for the AI Media Factory team. It provides a durable record of discussions, decisions, and action items.

## Scope

- Meeting agendas and attendees.
- Discussion summaries.
- Decisions reached and action items assigned.

## Naming Convention

Meeting note files are named using the meeting date in ISO format followed by a short, hyphenated topic:

```
YYYY-MM-DD-topic.md
```

For example, `2026-01-15-quarterly-planning.md`. Significant decisions recorded here should be promoted to an Architecture Decision Record in `docs/decisions/` where appropriate.
