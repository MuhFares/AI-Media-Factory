# Sprints

This directory holds sprint planning documentation, backlog notes, and velocity tracking for the AI Media Factory team.

## Scope

- Sprint goals and planned scope.
- Backlog items committed to each sprint.
- Velocity notes and retrospective summaries.

## Naming Convention

Sprint files are named using a zero-padded sprint number:

```
sprint-NN.md
```

For example, `sprint-01.md` or `sprint-12.md`. Each sprint document should capture the sprint goal, committed backlog, outcomes, and velocity observations.
