# Architecture

This directory documents the system architecture of the AI Media Factory platform. It is the destination for content being expanded from the legacy `docs/architecture.md` file.

## Scope

- System architecture and high-level design.
- C4-style diagrams (System Context, Container, Component, and Code levels).
- Data flow across services and pipelines.
- Scaling strategy, capacity planning, and performance considerations.
- Service boundaries, ownership, and integration contracts.
