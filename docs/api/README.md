# API

This directory documents the public and internal APIs of the AI Media Factory.

## Scope

- API reference and endpoint documentation.
- OpenAPI specifications.
- Endpoint contracts, including request and response schemas.
- Authentication and authorization model.

## Cross-Reference

The API implementation lives in `apps/api`. This directory documents the interface and contracts; `apps/api` contains the executable service. Specifications here should reflect the deployed behavior of `apps/api`.
