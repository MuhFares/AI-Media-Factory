# Morroway Adaptive Pilot Content System V1

**Status:** READY_FOR_INITIAL_LEARNING_BATCH_PRODUCTION  
**Brand:** Morroway  
**Operational model:** PERFORMANCE_LED + AGENT_RECOMMENDED + OWNER_GOVERNED

The pilot is a learning system, not a fixed campaign. Its total video count and duration are adaptive; no permanent performance threshold determines success or failure.

## Operating loop

`IDEA → RESEARCH → CONTENT BRIEF → SCRIPT → VISUAL PLAN → PRODUCTION → QA → OWNER APPROVAL → PUBLISH → MEASURE → PERFORMANCE ANALYSIS → AGENT REVIEW → OWNER REVIEW / OPTIONAL OVERRIDE → NEXT ACTION`

Routine analysis produces a recommendation. The owner can approve, modify, override, force continuation or pause, request more evidence, or change priority. Overrides append to the record; they never rewrite an agent’s earlier conclusion.

## Initial learning batch

Only four items are selected for production: two Historical POV/Perspective and two Cinematic Fantasy/Imaginative Storytelling. They are deliberately distinct enough to begin learning, but this is not the pilot’s total scope.

| ID | Pillar | Test focus | Duration |
|---|---|---|---|
| MW-HIS-001 | Historical | Sensory-first, source-supported POV | 35–50s |
| MW-HIS-002 | Historical | Curiosity hook with delayed factual reveal | 40–55s |
| MW-FAN-001 | Fantasy | Immediate impossible visual reveal | 25–40s |
| MW-FAN-002 | Fantasy | Character-led emotional premise | 35–50s |

Each historical item requires research sign-off before scripting. Every item requires QA and owner approval before any publication.

## Performance review

`MORROWAY_CONTENT_PERFORMANCE_REVIEW` uses only metrics actually provided by each platform. It evaluates individual content, format and hook performance, pillar performance, production efficiency, emerging audience behavior, repeated patterns, and anomalies. It distinguishes signals from noise and uses account baseline, early velocity, retention, quality of engagement, follow conversion, share/save behavior, and production efficiency where sufficient data exists.

Every recommendation records: `DECISION`, `CONFIDENCE`, `EVIDENCE`, `MISSING_EVIDENCE`, and `RECOMMENDED_NEXT_TEST`. Valid decisions are Scale, Continue, Iterate, Retest, Pause, or Retire. A transition to scale is evidence-based and owner-governed.
