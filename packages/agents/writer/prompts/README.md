# Writer Agent — Prompts

This folder holds the versioned system and user prompt templates that define the writer agent's voice, formats, and drafting behavior. Templates are versioned so prompt changes can be reviewed, compared, and rolled back.

Prompts here integrate with `packages/prompts`, the shared prompt registry, which provides common building blocks, formatting conventions, and version tracking across all agents. No prompt templates are defined yet; this README anchors the folder and documents its intent.
