# Writer Agent — Tests

This folder holds eval-style tests for the writer agent. Rather than only asserting on code paths, these tests evaluate agent behavior and output quality.

- Prompt regression tests to catch unintended changes when prompts are updated.
- Output schema validation to ensure scripts and captions conform to expected contracts.
- KPI and behavioral evals that check tone, readability, and brand-voice adherence.

These are placeholders for now; no tests are implemented yet. This README anchors the folder and documents its intent.
