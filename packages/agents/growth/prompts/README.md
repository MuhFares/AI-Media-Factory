# Growth Agent — Prompts

This folder holds the growth agent's versioned system and user prompt templates.

Prompts are versioned so changes can be reviewed, evaluated, and rolled back. The shared prompt registry in `packages/prompts` is the canonical source; agent-specific overrides and bindings are documented here.

Prompt families for this agent:

- System prompts establishing the growth-optimization role and experimentation discipline.
- User/task templates for hook/title generation, experiment design, and retention analysis.
