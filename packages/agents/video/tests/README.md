# Video Agent — Tests

This folder holds eval-style tests for the video agent. Rather than only asserting on code paths, these tests evaluate agent behavior and output quality.

- Prompt regression tests to catch unintended changes when prompts are updated.
- Output schema validation to ensure render outputs meet format, resolution, and duration contracts.
- KPI and behavioral evals that check pacing, caption accuracy, and quality thresholds.

These are placeholders for now; no tests are implemented yet. This README anchors the folder and documents its intent.
