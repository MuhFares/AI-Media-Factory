# SEO Agent — Tests

This folder holds eval-style tests for the SEO agent. Rather than only asserting on code paths, these tests evaluate agent behavior and output quality.

- Prompt regression tests to catch unintended changes when prompts are updated.
- Output schema validation to ensure titles, tags, and descriptions conform to platform limits and contracts.
- KPI and behavioral evals that check keyword relevance and policy compliance.

These are placeholders for now; no tests are implemented yet. This README anchors the folder and documents its intent.
