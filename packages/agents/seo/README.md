# SEO Agent

The SEO agent maximizes discoverability. It optimizes titles, descriptions, tags, and structured metadata so content ranks well in search and platform recommendation systems. It works closely with `research` upstream and `writer` and `publisher` alongside it.

## Responsibilities

- Perform keyword research and map target terms to each piece of content.
- Optimize titles, descriptions, tags, and chapters for search and discovery.
- Advise the `writer` agent on keyword placement and content structure.
- Generate platform-specific metadata within character and formatting limits.
- Monitor ranking signals and recommend metadata updates over time.

## Inputs

- Keyword and demand signals from the `research` agent.
- Draft copy and scripts from the `writer` agent.
- Historical ranking and traffic data from the `analytics` agent.

## Outputs

- Optimized titles, descriptions, and tag sets for the `publisher` agent.
- Keyword targets and structure guidance fed back to the `writer` agent.
- Metadata update recommendations for already-published content.
- Structured data and chapter markers for supported platforms.

## Dependencies

- `research` — provides demand and keyword signals.
- `writer` — collaborates on copy optimization.
- `publisher` — applies the metadata at publish time.
- `analytics` — measures ranking and discovery outcomes.

## KPIs

- Search and recommendation impressions per published item.
- Click-through rate from search and suggested feeds.
- Ranking position for targeted keywords.
- Share of discovery-driven traffic versus total traffic.

## Future Roadmap

- Add continuous metadata re-optimization based on live ranking data.
- Support emerging platform ranking signals as they appear.
- Introduce competitive SERP and share-of-voice tracking.
- Build predictive scoring of metadata before publish.
