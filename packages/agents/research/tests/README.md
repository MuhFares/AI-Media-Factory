# Research Agent — Tests

This folder holds eval-style tests for the research agent. Rather than only asserting on code paths, these tests evaluate agent behavior and output quality.

- Prompt regression tests to catch unintended changes when prompts are updated.
- Output schema validation to ensure briefs and topic rankings conform to expected contracts.
- KPI and behavioral evals that check citation accuracy and topic relevance.

These are placeholders for now; no tests are implemented yet. This README anchors the folder and documents its intent.
