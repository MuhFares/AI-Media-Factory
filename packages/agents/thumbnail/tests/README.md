# Thumbnail Agent — Tests

This folder holds eval-style tests for the thumbnail agent. Rather than only asserting on code paths, these tests evaluate agent behavior and output quality.

- Prompt regression tests to catch unintended changes when prompts are updated.
- Output schema validation to ensure generated assets meet dimension and format contracts.
- KPI and behavioral evals that check composition quality and brand-safety compliance.

These are placeholders for now; no tests are implemented yet. This README anchors the folder and documents its intent.
