# Finance Agent — Tests

This folder holds eval-style tests for the finance agent. These are placeholders for now; no logic is implemented yet.

Planned test categories:

- **Prompt regression** — detect behavioral drift when prompts or models change.
- **Output schema validation** — ensure financial summaries conform to the shared schemas in `schemas/`.
- **KPI / behavioral evals** — verify numerical accuracy, budget-enforcement behavior, and correct escalation on overruns.
