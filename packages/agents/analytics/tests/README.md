# Analytics Agent — Tests

This folder holds eval-style tests for the analytics agent. Rather than only asserting on code paths, these tests evaluate agent behavior and output quality.

- Prompt regression tests to catch unintended changes when prompts are updated.
- Output schema validation to ensure reports and metric rollups conform to expected contracts.
- KPI and behavioral evals that check insight accuracy and attribution coverage.

These are placeholders for now; no tests are implemented yet. This README anchors the folder and documents its intent.
