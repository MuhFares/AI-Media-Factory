# Instagram Templates

Instagram and Reels content templates for the AI Media Factory platform. This folder holds reusable scaffolding for Instagram publishing, including caption formats, hashtag sets, and cover formats.

Contents are runtime-generated and git-ignored; this README and .gitkeep anchor the folder.

## Typical Contents

- Caption templates with placeholder fields.
- Curated hashtag sets for reuse.
- Cover and thumbnail formats for Reels and feed posts.
