# YouTube Templates

YouTube-specific content templates for the AI Media Factory platform. This folder holds reusable scaffolding for YouTube publishing, including title formats, description layouts, end-screen definitions, and chapter formats.

Contents are runtime-generated and git-ignored; this README and .gitkeep anchor the folder.

## Typical Contents

- Title templates and formatting conventions.
- Description layouts with placeholder fields.
- End-screen and card configurations.
- Chapter and timestamp formats.
