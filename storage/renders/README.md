# Renders

Rendered media output produced by the AI Media Factory worker. This folder holds the finished render artifacts generated during media production workflows, including video, image, and audio renders.

Contents are runtime-generated and git-ignored; this README and .gitkeep anchor the folder.

## Characteristics

- Files are produced by rendering jobs executed on the worker.
- Output formats include video, image, and audio media.
- Large artifacts may be moved to object storage or cleaned up per retention policy.
