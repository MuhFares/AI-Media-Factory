# Exports

Finished, exportable deliverables produced by the AI Media Factory platform. This folder holds completed outputs intended for delivery or download, such as generated reports, data extracts, and published-content bundles.

Contents are runtime-generated and git-ignored; this README and .gitkeep anchor the folder.

## Characteristics

- Artifacts represent completed, deliverable outputs rather than intermediate state.
- Bundles may be retained according to configured retention policies.
- Treat exported deliverables as potentially sensitive and handle them accordingly.
