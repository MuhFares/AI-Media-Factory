# Prompt Knowledge

This directory holds curated prompt engineering knowledge for agent retrieval.

## Scope

- Proven prompt patterns and templates.
- Prompt engineering lessons and heuristics.
- Guidance on structuring instructions, context, and constraints.

## Distinction from `packages/prompts`

This directory is curated knowledge about prompting — the accumulated lessons and patterns that inform how prompts should be written. `packages/prompts` is the runtime prompt registry that stores and serves the operational prompts used by the system. Knowledge here guides the design of prompts; `packages/prompts` holds the prompts themselves.
