# Lessons Learned

This directory holds curated lessons learned for agent retrieval, feeding the organization's continuous improvement loop.

## Scope

- Post-mortems from incidents, campaigns, and experiments.
- Retrospective summaries and their outcomes.
- Distilled "lessons learned" intended to prevent repeated mistakes and reinforce what works.

Content here informs agents so that past experience shapes future decisions, closing the loop between outcomes and continuous improvement.
